# Suivi W27

Page en ligne : https://s2n24hffwy-oss.github.io/suivi-w27/

Glisse le rapport brut W27_Daily_Shipment_Report du matin dans la page. Elle produit deux rapports, en Excel ou en PDF : la Commande du Programme (les Customer PO que tu coches, la page apprend tes habitudes) et la Commande Special (les PO qui contiennent SPECIAL ou qui commencent par QB-TEZ, QB-FAS, HNC-TEZ, HNC-FAS, MB-TEZ, MB-FAS, plus ceux ajoutés à la main).

Le fichier Excel est lu dans le navigateur et n'est envoyé nulle part. La mémoire des PO et les listes de préfixes sont gardées dans le navigateur utilisé.
